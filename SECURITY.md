# Security policy

## Reporting a vulnerability

Please **do not** report security vulnerabilities through public issues, discussions
or pull requests.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/febsolutions/feb-eventsourcing/security/advisories/new)
("Security" tab → "Report a vulnerability"). Include what you found, how to reproduce
it, and the affected package versions.

You will get an acknowledgement as soon as possible. We will investigate, keep you
informed about the fix, and credit you in the advisory unless you prefer otherwise.

## Supported versions

Security fixes are made for the latest released minor version of the current major
version (9.x).
